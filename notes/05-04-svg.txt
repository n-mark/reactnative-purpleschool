Введение:
SVG часто используются для отрисовки иконок и других элементов.
В React Native и Expo нет нативной поддержки SVG, требуется установить дополнительную библиотеку.

Установка React Native SVG:
Важно установить библиотеку react-native-svg для работы с SVG в Expo.
Для установки используйте команду: npx expo install react-native-svg.

Использование SVG:
SVG можно экспортировать или скопировать готовый SVG-код.
Вставка SVG кода напрямую в код React Native не сработает.

Трансформация SVG в компонент React Native:
Используйте svgr конвертер для преобразования SVG в JSX код, совместимый с React Native.
Создайте React Native компоненты для иконок (iclosed.tsx и iopened.tsx).
Очистите и адаптируйте полученный код для использования в проекте.

Подключение и использование SVG компонентов:
Импортируйте и используйте SVG компоненты как обычные React компоненты.
Для визуализации изменений может потребоваться перезапустить сервер сборки.
