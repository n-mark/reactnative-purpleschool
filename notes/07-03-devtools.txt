Основные инструменты:
Встроенный отладчик
Chrome DevTools

Активация встроенного отладчика:
iOS: Command D / Двойное трясение устройства
Android: Control M / Двойное трясение устройства

Возможности встроенного отладчика:
Reload: Перезагрузка приложения для исправления багов.
Show Element Inspector:
Позволяет инспектировать элементы приложения на устройстве.
Аналогично Chrome DevTools, отображает параметры элементов.

Дополнительные функции:
Performance: Мониторинг производительности
Network: Просмотр сетевых запросов к backend
Touchables: Отображение областей доступных для нажатия.

Отладка JavaScript:
Открытие JS Debugger через панель разработчика:
Активация через Command J в консоли.
Возможность работы с JavaScript кодом в браузере.

Применение Chrome DevTools:
Позволяет инспектировать элементы, смотреть сетевые запросы и мониторинг производительности в браузере.
