Шаг 1: Работа в Figma
Режимы в Figma: При входе встречаем два режима – "Дизайн" для перемещения элементов и "Dev" для экспорта графики и измерения свойств.
Стилизация: Figma по умолчанию предлагает стилизацию для CSS, iOS, а также для Compose и XML, но не для React Native.
Преобразование стилей: Необходимо трансформировать CSS стили в стили React Native вручную (например, border-radius в borderRadius) или использовать предустановленные константы.

Шаг 2: Использование плагина React Native Styling Inspector
Установка и запуск: В DEV-режиме найти и запустить плагин, благодаря которому можно просмотреть и скопировать необходимые стили напрямую в проект React Native.
Преимущества плагина: Позволяет быстро получить стили, необходимые для стилизации элементов в React Native, без необходимости ручного перевода из CSS.

Шаг 3: Экспорт графики и инспектирование элементов
Инспектирование: Нажатие на элемент позволяет просмотреть его свойства. Использование Alt показывает расстояние до границ блока.
Экспорт графики: Для экспорта изображений доступны форматы SVG, PNG, JPEG. Более детально экспорт будет рассмотрен позже.

Шаг 4: Практика
После ознакомления с инструментами Figma и плагином React Native Styling Inspector переходим к практическому занятию. Необходимо создать общий лейаут, используя изученные инструменты и флексбоксы.
