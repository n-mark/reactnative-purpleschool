Цель упражнения:

Создать кастомную нотификацию для отображения сообщений об ошибках.

Шаги:
Создание компонента ErrorNotification в папке Shared.
Внутри ErrorNotification, создать ErrorNotification.tsx для реализации компонента.
Определение пропсов через ErrorNotificationProps.tsx:
Error: String | Undefined (в зависимости от наличия ошибки).

Ключевые моменты:
Использование useState для контроля отображения нотификации.
Автоматическое исчезновение нотификации спустя 3 секунды с помощью setTimeout в useEffect.
Правильная очистка таймера с помощью clearTimeout для избежания утечек памяти.

Стилизация:
Создание объекта стилей с использованием StyleSheet.
Абсолютное позиционирование и задание размеров.

Итог: При возникновении ошибки появляется нотификация в верхней части экрана с текстом ошибки, которая автоматически исчезает через 3 секунды. Добавление стилей для визуального оформления. Учтены особенности реализации для избежания ошибок при рендере в условиях React.
