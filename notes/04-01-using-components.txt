1. Введение в React Native

Основное отличие разработки в React Native от веб-разработки: использование нативных компонентов вместо стандартных HTML элементов (div, p и т.д.).
Попытка использования не нативных элементов приводит к ошибкам.
2. Использование нативных компонентов

В React Native доступен ограниченный, но достаточный набор компонентов для создания приложения любой сложности.
Возможность добавления дополнительных компонентов через Expo или установка пакетов из React Native community.
3. Основные компоненты

View: аналог div в вебе, служит контейнером для других компонентов.
Text: компонент для отображения текста
Другие важные компоненты: Switch, Modal, Image, FlatList, Activity Indicator и др.
4. Добавление и работа с компонентами

Пример добавления TextInput и Button.
Все компоненты должны быть явно импортированы из библиотеки React Native.
Нативные компоненты могут выглядеть по-разному на разных платформах (iOS, Android).
5. Стилизация компонентов

Возможность стилизовать и создавать кастомные компоненты для единого дизайна приложения на разных платформах.
Обсуждение способов стилизации компонентов будет в следующих разделах курса.
6. Заключение

Основы работы с компонентами в React Native включают в себя использование нативного набора элементов и их стилизацию.
Следующие шаги обучения будут включать в себя более глубокое изучение стилизации и разработки полноценных приложений с использованием различных компонентов.
