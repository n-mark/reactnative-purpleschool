Цель урока: Научиться добавлять и настраивать изображение при разработке приложения.

Шаги выполнения:

Экспорт изображения:
Выделите группу изображения.
Выберите формат экспорта (PNG, JPEG)
Экспортируйте с удвоенным качеством для совместимости с устройствами с высокой плотностью пикселей.

Добавление assets:
Перейдите к assets вашего приложения.
Добавьте экспортированный asset (логотип в формате PNG).

Использование изображения:
Импортируйте компонент Image из React Native.
Установите источник изображения через source и require, указывая путь к asset.

Настройка изображения:
Задайте размеры изображения с помощью свойства style.
Настройте поведение изображения в контейнере с помощью resizeMode (например, contain для корректного показа).

Выбор режима отображения:
Рассмотрите различные режимы resizeMode: stretch, repeat, cover, contain и center.
Выберите оптимальный режим для нужного вам вида изображения на странице.

Заключение: Использование изображения на странице логина требует внимательного подхода к выбору формата, качества, размеров и режима отображения. React Native предлагает гибкие инструменты для работы с изображениями через компонент Image. С помощью свойства source и require, можно легко добавить локальный ассет, а дополнительные свойства позволяют настроить внешний вид изображения в соответствии с дизайном страницы.
