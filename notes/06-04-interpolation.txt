Цель лекции: Научиться применять интерполяцию для анимации в программировании UI.

Основные понятия:

Интерполяция - процесс преобразования диапазона входных значений в выходной диапазон нового размера.
Пример использования: Преобразование численных значений в цвета для анимации кнопки.

Шаги реализации интерполяции:

Изначальные действия:
Убираем использование valueXY.
Инициализируем обычную value с начальными значениями (например, 100).

Создание целевого значения:
Определяем Animated.value.
Настраиваем целевой color через интерполяцию этого значения.

Конфигурация интерполяции:
Input range: Задаем входной диапазон (0 до 100).
Output range: Определяем выходной диапазон, например, изначальный цвет в целевой.

Применение интерполяции:
Модифицируем Animated.Timing для адаптации целевого значения.
Плавно изменяем color в соответствии с изменениями value.

Привязка к UI элементам:
Указываем изменяющийся color в стилях кнопки.

Практический пример:
Демонстрация анимации кнопки, меняющей цвет с исходного на целевой при изменении value.
