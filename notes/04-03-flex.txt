Что такое Flex?
Flex - основной инструмент для верстки и компоновки элементов в React Native.
Отличается от CSS, где используются гриды и флексы, в React Native гридов нет.
Flex позволяет располагать элементы горизонтально и вертикально, управлять их размерами и отступами.

Почему Flex?
Единственный подход к компоновке элементов в React Native.
Интуитивно понятный для тех, кто знаком с CSS Flexbox.

Основные свойства Flex:
Flex Direction: Определяет направление элементов в контейнере.
column (по умолчанию): Элементы располагаются вертикально.
row: Элементы располагаются горизонтально.
column-reverse и row-reverse: Обратное расположение элементов.

Пример использования Flex для расположения элементов:
Создание базового контейнера без стилей приведет к расположению элементов на верху экрана.
Добавление marginTop для отступа от верха экрана.
Создание дочернего контейнера для компоновки текста и кнопки.
Применение flexDirection для горизонтального расположения текста и кнопки.
По умолчанию элементы располагаются друг за другом вертикально.
Изменение flexDirection на row позволяет располагать элементы горизонтально.

Выводы:
Использование Flex в React Native позволяет эффективно управлять расположением и размерами элементов интерфейса.
flexDirection является ключевым свойством для определения основной оси размещения элементов.
В следующей лекции будет рассмотрено больше свойств Flex, позволяющих управлять расположением элементов внутри контейнеров.
