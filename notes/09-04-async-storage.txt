Введение в Persistent Storage:

Persistent Storage в приложениях позволяет сохранять данные между сессиями.
В React Native ранее использовался Async Storage, но теперь он устарел.
Существует множество пакетов в сообществе для работы со стейтом.
Выбор подходящего пакета:

Использование https://reactnative.directory для поиска нужного пакета. Можно фильтровать по критериям, например, совместимость с Expo.
Сортировка по популярности на GitHub для выбора надёжного решения.
Выбор падает на ReactNativeAsyncStorage для работы в разных платформах: Android, iOS, macOS, web, Windows.
Основы Async Storage:

Ограничения по размеру хранения данных, но обычно достаточно для текстовой информации.
Интеграция с Jotai для управления состоянием.
Установка и использование Async Storage:

Установка через npm.
Примеры работы с ключами и значениями: сохранение (setItem), чтение (getItem), удаление (removeItem), получение всех ключей (getAllKeys).
Практика:

Демонстрация работы с Async Storage на примере: сохранение строки, чтение, удаление и повторное чтение.
Обращение внимания на ограничения хранилища, например, общий размер данных 6 мегабайт, что обычно достаточно для текстовых данных.
Замечание о различной реализации под каждую платформу (например, SQLite под Android).
