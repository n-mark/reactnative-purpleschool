Цель лекции:
Научить создавать несколько страниц и осуществлять навигацию между ними в рамках одного приложения.

Основные понятия:
Роутинг - механизм, позволяющий навигировать между разными частями приложения или сайта.
Компонент Page - отдельная страница в приложении.
Компонент Link - используется для создания переходов между страницами.

Шаги:

Создание страницы:
Каждая страница имеет уникальное название. Пример: index.tsx для главной страницы.
Для добавления новой страницы создается новый файл, например, login.tsx или restore.tsx.

Навигация и роутинг:
Определение пути (URL) для новой страницы, например, /login или /restore.
Использование компонента Link для создания ссылок на другие страницы в приложении.
Прописывание пути в свойстве Link для перехода, например, <Link to="/restore">Восстановить пароль</Link>.

Структура директорий:
Помимо создания отдельных файлов для каждой страницы, можно организовывать файлы по папкам, например, папка restore с файлом restore.tsx внутри.
