Часть 1: Установка Jotai и подготовка к созданию атома

Введение и Установка Jotai
Начинаем с создания простого атома для профиля пользователя.
Установка через команду npm install jotai.
После установки, запускаем проект через npm start.

Создание первого атома
Цель: Сохранить базовую информацию пользователя (ID, имя, фамилия, фото).
Создаём файлы userState.ts и userModel.ts в модели пользователя.
userState.ts отвечает за состояние.
userModel.ts содержит описание пользователя и его параметры.


Часть 2: Работа со State и Jotai

Описание State
Создаём интерфейс пользователя с минимально необходимыми полями.
Описание состояния включает профиль пользователя, индикатор загрузки, и поля для ошибки.

Создание атома с JotAi
Использование atom для описания состояния профиля пользователя.
Указываем начальное состояние: профиль null, загрузка false, ошибка null.


Часть 3: Практическое применение атома

Использование в приложении
Демонстрируем работу с созданным атомом, используя useAtom для получения и использования состояния в компоненте.
Пример вывода имени пользователя из профиля.
