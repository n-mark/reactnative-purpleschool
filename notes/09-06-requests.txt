Основные шаги:

Установка Axios:
Открыть консоль и выполнить команду npm install axios.
Axios выбран за его способность к легкой типизации ответов.

Создание функции для логина:
Создать асинхронную функцию getLogin на индексной странице.
Использовать Axios для выполнения POST запроса. Параметры запроса - e-mail и пароль.

Настройка API:
В файле API.ts, экспортировать пути для авторизации (например, метод login).
Пример URL: https://purpleschool.ru/api-v2.
Внести префикс URL для использования в различных методах API.

Тестирование логина:
Использовать useEffect для вызова getLogin при монтировании компонента.
Проверка ответа сервера в консоли.

Создание тестового пользователя:
​​​​​​​Регистрация пользователя на платформе для тестирования (например, Василий Пупкин, email: vasya@pupkin.ru, пароль: 12345678).

Типизация ответа от сервера:
Создать интерфейс AuthResponse в файле auth.interfaces.ts для типизации получаемого Access Token.
Использовать этот интерфейс для типизации в Axios запросе.

Обработка ошибок:
​​​​​​​​​​​​​​Проверить поведение при отправке неверных данных (например, неверного пароля).
