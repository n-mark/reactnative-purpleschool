Определение модели авторизации

Перейти к сущности авторизации для работы с ней.
Создать файл authState.ts для описания состояния.
Интерфейс authState включает в себя:
accessToken: строка или null.
isLoading: boolean.
error: строка или null.


Создание персистентного атома

Необходим asyncStorage из react-native-async-storage.
Используем метод createJSONStorage из jotai/utils для создания хранилища.
Создать storage с использованием asyncStorage.
Определить authAtom как atomWithStorage с ключом, начальным состоянием (accessToken null, isLoading false, error null) и ссылкой на созданный storage.


Применение персистентного хранения

Персистентное хранилище автоматически сохраняет и обновляет данные в asyncStorage, подходит для частей приложения с повторным использованием данных в офлайне.
