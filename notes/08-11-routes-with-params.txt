Цель лекции: Понять, как создавать и использовать динамические роуты в проектах

Основные моменты:

Введение в динамические роуты:
​​​​​​​Необходимость в динамических роутах возникает при необходимости отображения страницы или экрана в зависимости от параметров, например, идентификатора (ID) или alias.

Создание папки для курса:
Для демонстрации создаётся папка course в директории приложения.
Роут /course будет вести на данную папку.

Добавление динамического параметра:
Для создания динамического роута используются квадратные скобки, например, /coulse/[alias].
Это позволяет передавать различные параметры в URL, делая роут динамическим.

Компонент Page для отображения курса:
​​​​​​​​​​​​​​Создание React Native компонента для отображения информации о курсе с использованием полученных параметров.

Использование параметра в роуте:
​​​​​​​​​​​​​​Для перехода на страницу курса необходимо перейти по URL, содержащему alias курса, например, /course/typescript.

Получение параметра из URL:
​​​​​​​​​​​​​​С помощью hook useLocalSearchParams, можно извлечь параметры из URL, такие как alias, для дальнейшего использования в приложении.

Применение динамических роутов:
​​​​​​​​​​​​​​Получив параметр, можно запрашивать данные с сервера или выполнить другие действия в зависимости от полученного значения.
