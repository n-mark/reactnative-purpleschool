Основные Понятия:
Цель Лекции: Научиться делать кнопки более интерактивными через анимацию с использованием свойств Pressable.
Свойства Pressable: onPressIn, onPressOut
Дополнительно: Обозначение onLongPress для длительных нажатий.
Реализация Анимации:
Цвета Кнопок:
Стандартное состояние: primary
При нажатии (Hover): primary-hover
Свойства Для Анимации:
onPressIn: Начало нажатия, вызывается анимация fadeIn.
onPressOut: Конец нажатия, вызывается анимация fadeOut.
Функции Анимации:
fadeIn: Затемняет кнопку при нажатии.
fadeOut: Возвращает исходный вид кнопки при отпускании.
Типизация и Пропсы:
Передача event и использование GestureResponderEvent для управления событиями.
Возможность добавления сторонних событий onPressIn/Out через пропсы.
