Шаги Реализации:
Установка ESLint и Плагинов:
Основная Установка:
Ввод основной команды через npm для установления ESLint и TypeScript зависимостей.
Дополнение установки с плагинами для поддержки React Native.
Настройка ESLint:
Создание файла конфигурации .eslintrc.json.
Объяснение и настройка стандартных и специфических правил для React Native, включая автоматизацию форматирования кода.

Настройка VS Code для Автокоррекции:
Добавление settings.json в .vscode директорию для конфигурации автосохранения и форматирования ESLint.
Проведение необходимых манипуляций для активации настроек (перезапуск VS Code, если требуется).

Применение и Демонстрация:
Демонстрация решения общих и специфических проблем линтинга и форматирования.
Примеры использования правил React Native, например, запрет на использование литералов цветов.
Отладка и форматирование кода, удаление ошибок.
